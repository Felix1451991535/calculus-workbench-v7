# V7.1 本次变更及验收边界

2026-10-07，1.4.0 Candidate。教材规则以 V7.1 为准，其他 V7 要求保留。

教材知识层 TEXTBOOK_ACCEPTED 和人工 VERIFIED 分开：前者检查来源及解析质量，后者保留人工确认记录；AI不能覆盖原件或事实版本。旧候选若可回溯到可靠 PDF 原文，也能用于教辅上下文，无需逐条点击确认。有冲突的视觉内容、无法排版的公式和缺失页面局部 NEEDS_VERIFY。

首次导入自动保存 full-book-build.json：整本范围、来源哈希、原文锚点、教材节点、关系、异常、跨页及孤立内容检查。调用模型需先获得内容发送同意与有效内存密钥。整本教学任务逐节保存、可暂停续做，重启后的失败任务可以重新开始并复用当前来源已通过审核的内容。连续三部分失败中止，不能将被Reviewer退回的内容计为通过。

目录和原文块不是最终教学粒度。AI生成的 concepts 拆分定义、符号、条件、证明目标/策略/步骤/隐藏构造、方法等；保存符号含义及有依据的关系，独立审核同时审查数学、教学深度和来源，程序额外拦截漏原文、漏正式陈述和缺证明教学节点。AI节点ID使用教材锚点、教学角色和同角色序号，展示标题变动不改变ID；同一锚点下增删相同角色节点时，序号可能变化，后续需要锚点子范围进一步细化。

支持 belongs_to、prerequisite、next、defines、uses、proves、example_of、exercise_of、confusable_with、derived_from；不把阅读顺序伪称为先修关系。AI结构与教材原文、教学和外部补充身份分开。数学符号自动扫描仅标记上下文需求，不能伪称已经识别含义；模型教学输出有具体符号含义后才展示。

36项自动测试通过，包括局部异常、跨页保留、ID稳定、原始数据不变、可靠来源用于问答、缺证明教学粒度拦截。真实教材验证见 docs/evidence/V71_REAL_BOOK.json；不包含用户原文。浏览器模拟模型测试不是真实模型数学验收。

未完成验收：全书138部分真实AI教学质量、语义知识关联和图片内容覆盖。孤立检查仅针对已经提取的内容，不能统计未被识别的图片或隐藏公式。所有内容在软件中显示实际审核进度，不能宣称已完成全书教学。

用户已明确要求同时完善开发环境。OMX 0.21.8、Windows便携psmux及经审核项目skills已配置；模型兼容性、团队与hooks的实际验证分别记录在 ENV_SKILLS_REPORT.md 与 ENV_RUNTIME_VALIDATION.md，安装状态不等于运行验收。原配置保留D盘备份。安装器及更新系统继续保留V7要求，既有安装通过软件内一键更新，原教材和学习记录不进入发行包。
