## 网络兼容与实际边界

本机 GitHub raw 频道多次超时；读取现有系统代理后，暂停旧版界面轮询时检查成功。实际升级复用该次成功检查保存的签名清单，然后通过软件下载、验签和安装。旧界面轮询会造成服务负担，新版已等待上一次请求结束再刷新。

本机 D:/Program Files/CalculusWorkbench/启动工作台.ps1 使用已有系统代理，并显式传给桌面程序和 Node 后台。只改变本机启动器和正确桌面快捷方式，原快捷方式已备份；不修改系统代理或全局网络变量。普通发行安装程序尚未内置自动读取 Windows 系统代理，需要代理的其他电脑仍有此兼容性限制。Node 运行时的代理支持依据 [官方文档](https://nodejs.org/api/http.html#httpsetglobalproxyfromenvproxyenv)，不是关闭 TLS 校验。

教材知识层忠实保留提取原文，存在源文本/OCR 数学错误时需要与已审讲解、扫描原件对照；不能把自动纳入理解为所有公式已人工核验。部分原文标题中的 LaTeX 仍以文本显示，正文公式已验收。整本教学、全站无障碍、弱设备性能和长期运行尚未完成验收。原 V7 中仍未实现或未验收的内容继续以 ACCEPTANCE_REPORT.md 为准，本次不宣称全部 V7 功能完成。

开发环境实际可用范围及 OMX Team 的 Windows 兼容性阻塞见 DEVELOPMENT_ENVIRONMENT.md 与 ENV_RUNTIME_VALIDATION.md。用户九项品质要求已保存到全局和项目 AGENTS.md；奖项仅作参考。
