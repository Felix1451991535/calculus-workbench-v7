桌面版1.2.1：下载 Desktop-Windows-x64.zip，完整解压至短目录（如D:\CalcWorkbench），双击“知微高数工作台.exe”。或运行Setup-1.2.1.exe安装，安装器创建桌面快捷方式。无需安装Node，不依赖打开浏览器。
软件内“任务动态”查看导入、识别、AI审查及更新进度和历史。课堂笔记支持Word .docx和TXT，原文件保留；Word公式与图片需要对照原件检查。
桌面程序旁workspace目录保存教材、学习记录、更新和备份；卸载保留workspace，删除它会丢失资料。更新核心功能在消息箱执行；桌面外壳的新版本也可使用新安装包覆盖安装。
Windows安装器尚未使用付费发行者证书签名；更新清单使用Ed25519签名校验。

知微 · 高等数学 AI 学习工作台（V7 独立重做）

1. Windows x64 发行包解压后双击“启动高数学习工作台.bat”。不要仅下载 GitHub 的 Source code ZIP。
2. 导入自己的教材 PDF。自动识别结果是候选，不是已核验事实。在“教材核验 → 对照文件”可添加同一本书的扫描/文字版本；原样保留，可切换查看。
3. 在“教材核验”对照原件确认定义、全部条件、符号及公式。扫描页可以选择来源批量识别，先试1–3页，逐页保存、暂停和失败续做；页面发送外部视觉服务前确认，按服务用量计费。
4. 在设置中填写 Text Model、Vision Model 和自己的 API Key。DeepSeek当前可用图像模型为 deepseek-flash。Key 仅保留于当前服务内存，服务重启后重新输入。
5. 生成知识页和 Tutor 回答前，确认相关教材片段及个人记录将发送给你配置的服务。视觉辅助会发送相关页图像。
6. AI 教学内容经过独立 Reviewer、引用与公式检查；这仍不是数学正确性的绝对保证。不通过的内容保留为待修订，不冒充教材原文。
7. 错题、TXT 课堂转写和复测证据在本地保存。诊断证据不足时显示待评估。
8. 顶部消息箱查看维护与在线更新。下载并校验补丁后点击立即更新。安装前备份；失败回滚。不要通过删除 data 目录升级。
9. “注册长期维护.bat”注册当前用户登录自检、每日20:00及周六10:00维护任务。任务不依赖聊天窗口；关机期间暂停，重启后补跑。移动应用目录后重新注册任务路径。
10. 普通发行版执行健康检查；源码工作副本可调用 Candidate 修复 Agent，需要配置模型及内存密钥。Agent 最多修复3轮，失败熔断；通过离线测试的 Candidate 仍需完整发布门槛，不直接覆盖 Stable。
11. 设置中可创建完整备份。关闭工作台服务后使用“恢复学习数据.bat”，填写 backups 中的备份名称。恢复前保留现有数据。

运行数据：data；备份：backups；维护报告：logs/maintenance；更新：updates；导出：exports。
本软件使用相对路径。发行包不包含任何人的教材、密钥、错题、聊天、数据库、日志或备份。

正式路线：可选OCR、视觉增强、联网Research Sandbox、原创出题与独立验题、期末个人资料和Word/PDF导出。未实现及未验证项以 ACCEPTANCE_REPORT.md 和 REQUIREMENTS_V7.md 为准，不把路线承诺写成已完成能力。

开发维护：npm ci / npm run build / npm test / npm run acceptance。
真实 DeepSeek 教学、视觉理解和内容深度验收需要有效API Key及真实教材；没有凭据时记为 BLOCKED，不伪造 PASS。

“知识框架”从章/节标题形成导航。详细目录保留全部原文，按原书章节排序，框架构建不调用模型。

教材框架直接来自纯文字PDF全文，按章、节、知识点、定义、定理、证明和例题展开原文。本机提取不调用AI；扫描版用作公式与图形对照。
