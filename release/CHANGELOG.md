# CHANGELOG

## 1.0.0 — V7 全新候选版本

- 中文阅读型学习界面，亮暗模式、知识导航、上下文Tutor、窄屏布局。
- PDF文本及可配置DeepSeek视觉候选，核验事实、稳定知识点、版本与原文锚点。
- 深度教学、独立Reviewer、严格JSON结构纠错与公式/引用发布闸门。
- 原始转写、错题、对话与派生整理，九维证据诊断及独立出题验题。
- Windows内置运行时、独立签名更新、备份与事务回滚，维护消息箱。
- 本机每日/每周维护任务、Candidate修复Agent及最多三轮熔断。

候选状态与限制：完整教材/长期运行验证尚未完成，联网研究、期末Word/PDF及可选OCR在正式后续路线。

- 补齐启动目录冲突、运行中手动更新保护，以及非法Agent补丁的持久三次熔断。
